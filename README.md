# 白いぼうし あらすじ絵本

あまんきみこ「白いぼうし」をもとにした、タップで進むあらすじ絵本です。
空色のタクシー、夏みかん、柳の下の白い帽子の場面を、9つの場面で読み進めます。

## 見かた

- 画面をタップすると始まります。下のボタンで次の場面へ、「もどる」で1つ前の場面へ進みます。
- 帽子は画面を直接タップしても拾えます。
- 右上の「音」ボタンで、BGMと効果音のオン・オフを切り替えます。
- スマホ（縦・横）、iPad（縦・横）、パソコンのブラウザで動きます。

## ファイル構成

```
index.html          ページ本体
css/style.css       見た目（色・文字・レイアウト）
js/main.js          絵の描画・動き・BGM・物語の進行
assets/img/         登場人物や小物の絵（WebP）
```

ライブラリやビルド作業は不要です。フォントだけ Google Fonts から読み込みます。

## 手元で動かす

`index.html` をブラウザで開けば動きます。

ローカルサーバーで確認したい場合は、このフォルダで次のどちらかを実行し、`http://localhost:8000` を開きます。

```
python3 -m http.server 8000
npx serve .
```

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのいちばん上に置いて push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で見られるようになります。

## 文章を直したいとき

物語の文章は `js/main.js` の `STEPS` にあります。
ふりがなは `漢字{かな}` の形で書くと自動で付きます（例：`帽子{ぼうし}`）。

## 絵を差し替えたいとき

`assets/img/` の同じ名前のファイルを置きかえます。背景が透明な WebP か PNG を使ってください（PNG にする場合は `js/main.js` のファイル名も合わせて変えます）。

| ファイル | 内容 |
| --- | --- |
| taxi.webp | 空色のタクシー |
| matsui.webp / matsui-head.webp | 運転手の松井さん（全身／運転席の顔） |
| matsui-shake.webp | 首をふる松井さん（アップ） |
| gentleman.webp / gentleman-head.webp | お客の紳士（全身／後ろの席の顔） |
| girl-head.webp / girl-leaning.webp | おかっぱの女の子（後ろの席の顔／身をのりだすアップ） |
| boy.webp / mother.webp | 虫とりあみの男の子とお母さん |
| hat.webp / natsumikan.webp / butterfly.webp | 白い帽子・夏みかん・紋白蝶 |
| willow.webp | 柳の木 |

信号機、お堀、ビル、菜の花畑、橋などの背景は `js/main.js` の中でプログラムで描いています。

## 権利について

- 原作の文章はそのまま載せず、場面ごとのあらすじとして書き直しています。原作は、あまんきみこ「白いぼうし」です。
- BGM はこのページ用のオリジナル曲で、ブラウザの中で演奏しています（音声ファイルはありません）。
- `assets/img/` の絵は制作者が用意したものです。公開リポジトリにする場合は、絵の利用条件を確認してください。
